# 📚 ReadWithMe

독서 경험을 공유하는 독서 게시판 웹 애플리케이션입니다.

## 프로젝트 개요

- **프로젝트명**: ReadWithMe
- **목적**: 독후감 및 리뷰 작성, 책 정보 공유를 통한 독서 커뮤니티 형성
- **개발 방식**: 바이브코딩 (AI 활용 개발)
- **사용 AI**: Claude (Anthropic)

## 주요 기능

- 회원가입 / 로그인
- 책 검색 및 등록
- 독후감 / 리뷰 작성
- 댓글 / 좋아요

## 팀원

| 이름 | 역할 |
|------|------|
| 이름 | 역할 |
|---|---|
| 남지원 | 공통 레이아웃 구현 (Header, TabNavigation, EmptyState), 독서 기록 탭 구현 (폼, localStorage 저장/조회), Jest 단위 테스트 작성 (커버리지 95%) |
| 문선영 | 통계 탭 구현 (출석 달력, 진도율 요약, 도넛 차트), Jest 단위 테스트 작성 (커버리지 95.6%) |
| 민지원 | 서재 탭 구현 (도서 목록, 검색, 정렬, 필터, 수정, 삭제), Jest 단위 테스트 작성 (커버리지 96.49%) |
