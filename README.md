# 📚 ReadWithMe

독서 기록을 관리하고 통계로 시각화하는 웹 애플리케이션입니다.

## 프로젝트 개요

- **프로젝트명**: ReadWithMe
- **목적**: 개인 독서 기록 작성, 서재 관리, 독서 통계 시각화
- **개발 방식**: 바이브코딩 (AI 활용 개발)
- **사용 AI**: Claude Code (Anthropic)

## 주요 기능

- 독서 기록 작성 (제목, 저자, 진도율, 별점, 느낀점 등)
- 서재 관리 (도서 목록 조회, 검색, 정렬, 필터, 수정, 삭제)
- 독서 통계 (평균 진도율, 상태별 도서 수, 월별 출석 달력, 도넛 차트)

## 팀원

| 이름 | 역할 |
|---|---|
| 남지원 | 공통 레이아웃 구현 및 독서 기록 탭 구현 (폼, localStorage 저장/조회), Jest 단위 테스트 작성 (커버리지 95%) |
| 문선영 | 통계 탭 구현 (출석 달력, 진도율 요약, 도넛 차트), Jest 단위 테스트 작성 (커버리지 95.6%) |
| 민지원 | 서재 탭 구현 (도서 목록, 검색, 정렬, 필터, 수정, 삭제), Jest 단위 테스트 작성 (커버리지 96.49%) |
