### - 기록탭
```
독서 기록 탭 기능을 구현해줘.

구현 범위
도서 정보 및 독서 내용 입력 폼
필수 입력 검증 (제목, 저자)
진도율 기반 독서 상태 자동 계산 (0% 읽고 싶음 / 1~99% 읽는 중 / 100% 완독)
별점 입력 (1~5점, 0.5 단위)
느낀점 / 기록하고 싶은 구절 최대 1000자 제한
localStorage 저장 (key: readWithMeBooks)
저장 후 데이터 유지 확인

localStorage 데이터 구조
bookId, recordNo, title, author, publisher
progressRate, status, startDate, finishDate, recentReadDate
rating, memo (impression, quote, oneLineReview)
dateLogs, createdAt, updatedAt

조건
서재 탭 담당자가 readWithMeBooks 기준으로 바로 작업할 수 있도록 데이터 구조 주석 남겨줘
브랜치는 feat/record, develop에 PR할 예정
기능 단위로 커밋 분리해줘
```

### - 서재탭

```
서재 탭 기능을 단계별로 구현해줘.
한 번에 전부 만들지 말고 아래 순서대로 하나씩 만들어줘.
1번 완료되면 내가 확인하고 커밋한 다음 2번 요청할게.
프로젝트 환경

React 19 + Vite 7
localStorage 기반 (백엔드 없음)
localStorage key: readWithMeBooks

구현 순서

도서 목록 카드 표시
검색 기능
정렬 기능
상태 필터 기능
수정 기능
삭제 기능

구현 기준
도서 목록 카드 표시

readWithMeBooks 키로 localStorage에서 데이터 불러오기
카드 형식으로 도서 목록 표시
표시 항목: 제목, 저자, 상태, 진도율, 최근 읽은 날짜, 별점
데이터 없을 때 빈 상태 메시지 표시

검색 기능

제목/저자 부분 일치 검색
대소문자 구분 없음
검색어 없으면 전체 목록 표시
검색 결과 없으면 결과 없음 안내 메시지 표시

정렬 기능

제목 가나다순
최근 읽은 날짜 최신순
최근 읽은 날짜 오래된 순
진도율 높은 순
별점 높은 순
날짜/별점 null인 경우 맨 뒤로 처리

상태 필터 기능

읽고 싶음 / 읽는 중 / 완독 / 전체 필터
상태는 progressRate 기준으로 자동 계산 (0% 읽고 싶음 / 1~99% 읽는 중 / 100% 완독)

수정 기능

모달 형식으로 수정 폼 표시
모든 입력 항목 수정 가능
필수 입력 검증 (제목, 저자)
진도율 0~100 범위 검증
별점 1~5, 0.5 단위 검증
수정 시 updatedAt 갱신
수정 후 localStorage 즉시 갱신

삭제 기능

삭제 전 확인 다이얼로그 표시
삭제 후 localStorage 즉시 갱신

기존 코드 참고

공통 컴포넌트: src/components/common/EmptyState.jsx
localStorage 유틸: src/utils/bookStorage.js, src/utils/localStorage.js
상태 계산: src/utils/bookStatus.js
기존 CSS 변수 활용: src/styles/global.css

1번부터 시작해줘.
```

```
- React 19 + Vite 7 기반 독서기록 웹앱

key: "readWithMeBooks"

  updatedAt: string
```

### jest 테스트 환경 설정
```
현재 프로젝트는 React 19 + Vite 7 기반이고 package.json의 "type"이 "module"로 설정되어 있어.

## 설치할 패키지 (devDependencies)
jest, @testing-library/react, @testing-library/jest-dom, jest-environment-jsdom, @babel/core, @babel/preset-env, @babel/preset-react, babel-jest

## 생성할 파일

### babel.config.js (프로젝트 루트)
- ESM 방식으로 export default 사용
- @babel/preset-env (targets: node current)
- @babel/preset-react (runtime: automatic)

### jest.config.js (프로젝트 루트)
- ESM 방식으로 export default 사용
- testEnvironment: jsdom
- setupFilesAfterFramework: ["<rootDir>/jest.setup.js"]
- transform: babel-jest로 js, jsx 처리
- moduleNameMapper: CSS 파일은 __mocks__/styleMock.js로 처리

### jest.setup.js (프로젝트 루트)
- import "@testing-library/jest-dom" 한 줄

### __mocks__/styleMock.js (프로젝트 루트)
- export default {} 한 줄

## package.json 수정
scripts에 아래 두 줄 추가:
"test": "jest",
"test:coverage": "jest --coverage"

## 설정 완료 후

오류가 있으면 원인 파악하고 수정까지 해줘.
```
