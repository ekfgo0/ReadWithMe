# 독서기록 앱 통계 탭 구현

## 프로젝트 개요
- React 19 + Vite 7 기반 독서기록 웹앱
- localStorage 기반 (백엔드 없음)
- 기존 팀원이 구현한 레이아웃 및 공통 컴포넌트 위에서 통계 탭만 구현

## 참고 문서
- 요구사항 명세서: https://github.com/ekfgo0/ReadWithMe/blob/main/docs/요구사항명세서.md
- WBS: https://github.com/trytur/read-with-me/blob/main/docs/WBS.md
- ERD: https://github.com/trytur/read-with-me/blob/main/docs/ERD.md

## localStorage 데이터 구조
key: "readWithMeBooks"
value: 아래 구조의 배열
{
  bookId: string,
  title: string,
  author: string,
  publisher: string,
  progressRate: number,         // 0~100
  status: "읽고 싶음" | "읽는 중" | "완독",
  startDate: string,
  finishDate: string,
  recentReadDate: string,
  rating: number,
  memo: { impression, quote, oneLineReview },
  dateLogs: [{ dateLogNo: string, readDate: "YYYY-MM-DD" }],
  createdAt: string,
  updatedAt: string
}

## 기존 프로젝트 구조
src/
├── components/
│   ├── common/       # EmptyState 등 공통 컴포넌트
│   └── layout/       # Header, TabNavigation
├── pages/
│   ├── ReadingRecordPage.jsx
│   ├── LibraryPage.jsx
│   └── StatisticsPage.jsx  # 현재 EmptyState만 있는 빈 껍데기
├── styles/
│   └── global.css    # CSS 변수 정의됨 (--color-primary 등)
└── App.jsx           # 탭 전환 구조 이미 구현됨

## 구현할 기능 (통계 탭)
요구사항 명세서 기준:

1. 월별 출석 달력
   - dateLogs.readDate 기준으로 독서한 날짜를 달력에 표시
   - 이전/다음 월 이동 가능

2. 진도율 통계
   - 전체 평균 진도율
   - 상태별 도서 수 (읽고 싶음 / 읽는 중 / 완독)
   - 총 독서 일수 (중복 날짜 제거한 고유 날짜 수)
   - 도넛 차트로 시각화

## 생성할 파일 목록

#### jest 테스트 환경 설정
```
현재 프로젝트는 React 19 + Vite 7 기반이고 package.json의 "type"이 "module"로 설정되어 있어.

Jest 테스트 환경을 설정해줘.

## 설치할 패키지 (devDependencies)
jest, @testing-library/react, @testing-library/jest-dom, jest-environment-jsdom, @babel/core, @babel/preset-env, @babel/preset-react, babel-jest

## 생성할 파일

### babel.config.js (프로젝트 루트)
- ESM 방식으로 export default 사용
- @babel/preset-env (targets: node current)
- @babel/preset-react (runtime: automatic)

### jest.config.js (프로젝트 루트)
- ESM 방식으로 export default 사용
- testEnvironment: jsdom
- setupFilesAfterFramework: ["<rootDir>/jest.setup.js"]
- transform: babel-jest로 js, jsx 처리
- moduleNameMapper: CSS 파일은 __mocks__/styleMock.js로 처리

### jest.setup.js (프로젝트 루트)
- import "@testing-library/jest-dom" 한 줄

### __mocks__/styleMock.js (프로젝트 루트)
- export default {} 한 줄

## package.json 수정
scripts에 아래 두 줄 추가:
"test": "jest",
"test:coverage": "jest --coverage"

## 설정 완료 후
npm test 실행해서 Jest가 정상적으로 동작하는지 확인해줘.
오류가 있으면 원인 파악하고 수정까지 해줘.
```
